## 🏛️ Company & Mission

**J AI ENTERPRISES** is disrupting the 30-year legacy of static PDFs and cloud-rented documents (Notion, Google Docs) by pioneering the **Living Document Format (`.ldocx`)**:
- 100% air-gapped, client-side autonomous document container (ZIP-64 + 64-byte binary framing header).
- Hardware-accelerated 3D WebGL / Three.js holographic models (`.glb`, `.gltf`, `.obj`, `.stl`).
- Real-time fluid temporal dynamics, particle physics sandboxes, and sandboxed JSX execution.
- SHA-256 Merkle proofs with ECDSA P-256 cryptographic signatures.

## ⚡ Live Vercel Deployment

Deploy this entire command centre online to Vercel in 1 click:

1. Import this repository into [Vercel](https://vercel.com/new).
2. Set Environment Variable:
   - `GEMINI_API_KEY`: Your Google Gemini API Key (get one for free at [aistudio.google.com](https://aistudio.google.com/)).
3. Click **Deploy**.
4. Open your live deployment URL to access the full 3D interactive office!

## 💻 Local Quick Start

```bash
# 1. Clone repository
git clone https://github.com/jayaraman2212066/ldoc_studio_offive.git
cd ldoc_studio_offive

# 2. Install dependencies
npm install

# 3. Configure Gemini API key
cp .env.example .env.local
# Set your GEMINI_API_KEY in .env.local

# 4. Build and start
npm run build
npm start
# Opens http://localhost:4520
```
